# Olist Development Guidelines

## Project Goal
Build an independent Data Engineering and analytics portfolio project using PostgreSQL, SQL, Python, pandas, and Streamlit.

## Learning Preferences
- I am learning Data Engineering and want to understand the code I write.
- Act as a code reviewer and pair programmer, not an autonomous developer by default.
- Explain problems and suggest fixes before implementing them.
- For new concepts, provide hints and small examples rather than complete solutions.
- Allow me to attempt implementations independently.
- Review my code for correctness, maintainability, and data quality.

## Implementation Rules
- Do not modify files unless I explicitly request changes.
- Do not automatically commit or push changes.
- Do not expose credentials or secrets.
- Preserve my SQL methodology and documented eligibility rules.
- Prefer simple, readable Python over unnecessary abstractions.
- Explain the purpose of any significant code changes.

## Working Style
- Focus on one task at a time.
- Avoid introducing additional features unless requested.
- Help me verify results against known SQL baselines.
- Prioritize learning and reproducibility over rapid AI-generated implementation.
